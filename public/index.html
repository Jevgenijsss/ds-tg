Telegram Credentials

First, get your Telegram API keys. These let the bot read messages from your channel.

  1. Open my.telegram.org in a new tab
  2. Log in with your phone number
  3. Click "API Development Tools"
  4. Fill in any App name (e.g. MyBot) and short name (e.g. mybot)
  5. Click "Create application"
  6. Copy the App api_id and App api_hash below
Telegram will send you a login code
Must start with @. You must be a member of this channel.
🔐

Verify Your Identity

Telegram sent a code to your phone (or Telegram app). Enter it below.

Check your Telegram app or SMS messages

Discord Setup

Now connect your Discord bot and choose which channel to post announcements in.

Create a Discord bot:
  1. Go to discord.com/developers/applications
  2. Click "New Application" → give it a name → Create
  3. Go to the Bot tab → click "Reset Token" → copy the token
  4. Scroll down, enable Message Content Intent
  5. Go to OAuth2 → URL Generator: check bot, then check Send Messages + Embed Links
  6. Open the generated URL → invite the bot to your server
Get your channel ID:
  1. In Discord, go to Settings → Advanced → enable Developer Mode
  2. Right-click your #announcements channel → Copy Channel ID
🚀
