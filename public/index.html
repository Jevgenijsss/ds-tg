🎮 Discord
How to create a Discord bot:
  1. Go to discord.com/developers/applications
  2. Click New Application → name it → Create
  3. Go to Bot tab → click Reset Token → copy the token
  4. Scroll down → enable Message Content Intent
  5. Go to OAuth2 → URL Generator → check bot → check Send Messages + Embed Links
  6. Open the generated URL → invite the bot to your Discord server
How to get the channel ID:
  1. In Discord: Settings → Advanced → enable Developer Mode
  2. Right-click your #announcements channel → Copy Channel ID
